# kernel 算子执行内核

> 对应架构 §4.1 | Sprint：S0.2

## 职责

算子执行的底层基座，提供**四种执行模式自动切换**：

| 执行模式 | 用途 | 一致性保证 |
|----------|------|-----------|
| 确定性精确 | 精确哈希去重、精确统计、Schema 校验 | 逐字节等价 |
| 近似/概率 | MinHash/SimHash、概率采样、近似分位 | 固定种子 + 误差界 |
| 流式 | 无界数据、在线清洗、实时过滤 | 窗口内等价 |
| 缓存/增量 | 大目录重复处理、增量更新 | 命中缓存即等价 |

## 子包规划（S0.2）

```
kernel/
├── exact       # 精确算术与精确哈希
├── approx      # 近似（种子化）
├── streaming   # 流式窗口执行
└── cache       # 缓存与增量
```

## 鲁棒性要求

空数据、超长记录、编码损坏、模态缺失、嵌套 Schema 漂移、时间戳乱序，均需确定性处理；不允许因单条脏记录中止整批。
