# datatemporal 数据时空·版本·血缘

> 对应架构 §4.4 | Sprint：S0.5

## 职责

对标 GeoVerse 的 spatiotemporal，把"数据的第 4 维"（版本/时间）做成一等维度，管理**数据集 + 数据实体的生命周期**，而非把版本当属性标签。

## 子包规划（S0.5）

```
datatemporal/
├── version   # 版本塔、快照
├── lineage   # 双向/字段级血缘
├── drift     # 漂移检测、数据衰老
└── replay    # 回放与回溯
```

## 核心能力

- **版本塔**：每次 recipe 执行产生新版本，记录算子图 + 参数 + 输入指纹
- **时序快照**：任意版本可提取当时数据集状态
- **增量更新**：仅重算受影响记录子集
- **可回放**：给定 recipe + 版本 + 种子，逐位复现
- **双向血缘**：输出追溯到输入与算子；输入预测下游影响
- **字段级血缘**：精确到 record / chunk 的产生路径
- **指纹机制**：输入输出内容指纹，检测血缘断裂
- **漂移检测**：跨版本统计分布对比
- **数据衰老**：时效性衰减评估

S0.1 骨架占位。`datatemporal_id` 为占位标识，供根包重导出验证。
