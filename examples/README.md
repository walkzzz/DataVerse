# DataVerse Examples

This directory contains example usage of the DataVerse library.

## Available Examples

- `apps/cli` — CLI tool demonstrating _common functions
- `apps/proof` — Proof & verification tool with 20+ assertions
- `apps/stats` — Statistical analysis tool with 5 datasets
- `apps/extcore` — Semantic package explorer
- `apps/info` — Project information tool
- `apps/bench` — Benchmark tool

## Quick Start

```bash
# Run CLI tool
moon run apps/cli/cmd/main --target native

# Run proof tool
moon run apps/proof/cmd/main --target native

# Run stats tool
moon run apps/stats/cmd/main --target native
```
